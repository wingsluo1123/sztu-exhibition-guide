# 遥控停止状态：只读记录方案

`tools/observe_mc_state.py`只订阅MC公共状态、硬件速度话题和本项目里程计，
默认记录30秒。没有控制发布者、输入源注册或控制服务调用，不会替操作者停车。
输出文件必须不存在。启动后须看到 `RECORDING_FRESH_STATE` 才说明已收到
500ms内的新鲜状态；没有新鲜状态时退出2。该提示不是物理试验放行。

2026-10-19操作者报告停止方式为L2+R2+创建键。机器人自带AimDK_X2 1.1.0
手册 `/agibot/software/aimdk/docs/cn/_build/html/zh-cn/dev/operation_guide/shutdown.html`
明确该组合切换阻尼，区别于L1+R1+创建键的零力矩。
阻尼改变身体支撑状态，未固定防跌保护时不能为了测试而按此组合。

23:00左右只读采到公共状态：输入源rc、优先级80，动作描述STAND_DEFAULT，
fsm=4；同条消息的动作枚举value=0。故保存全部原始字段，不把0当作站立或
阻尼的有效枚举，不只按描述或fsm单个字段判定成功。该快照不证明此前SDK
停止后何时交还了遥控，也不证明阻尼已触发。

在机器人已加载本项目及厂商消息环境的终端，可独立运行记录器：

```bash
cd ~/sztu
python3 tools/observe_mc_state.py --seconds 30 --output /tmp/mc_state_new.json
```

运行记录器本身不会改变机器人模式。没有针对当前试验的授权及保护确认时，
仅记录静止基线，不操作按钮、不发运动指令。下一次拟议试验限固定防跌保护
下、机器人静止时，由操作者触发一次阻尼，比较前后的原始状态和现场反应。
不发送非零SDK速度，不自动恢复站立或走跑，不重试；尚未执行或放行。
它只能核对遥控模式切换通道，不能证明运动中接管或地面停止距离。

报告保留全部输入的源年龄和原字段；超时/无效时间戳不抹去，明确标记。
NaN/Inf保存为字符串，避免丢失整个报告。硬件停止验证始终false，里程计
只是估计运动记录。程序中断或SSH退出不会给机器人发送停止命令。

机器人当前SDK的域42正例覆盖已知站立→阻尼描述变化、枚举持续0、过期状态、
非有限速度保留及无新增控制发布者。开发机SDK缺少McCommonState，不以其
跳过结果冒充通过；在机器人隔离域上验证实际消息契约。
