# APP 侧功能完善任务交接文档 (Handoff to APP Agent)

## 任务：完善 Robot_APP（HarmonyOS 北向客户端）的运动模式与挥手功能

### 背景

机器人侧（ROS 2 `bridge_server`）已完成开发并部署：它通过 **TCP 8888 端口**接收 UTF-8 文本指令（每条以 `\r\n` 结尾，服务端也容忍裸 `\n`），执行后回复一行确认。APP 侧只需**为每个按钮发送对应字符串**，所有机器人物理逻辑、模式切换安全序列都在服务端，APP 无需关心。

APP 工程：HarmonyOS ArkTS 项目 `Robot_APP`，相关文件：
- `entry/src/main/ets/pages/TcpClient.ets` — TCP 客户端，端口 8888，发送格式 `msg + "\r\n"`
- `entry/src/main/ets/pages/WebSocketClient.ets` — WebSocket 备用通道
- `entry/src/main/ets/pages/Index.ets` — 按钮与指令的对应关系（现有 `拍手`、`点头` 等手势按钮走同一路径，可作参考模板）
- `entry/src/main/ets/pages/RobotConnection.ets` — TCP/WebSocket 切换封装

### 需求：新增以下指令按钮

#### 一、运动模式组（新增按钮，建议放一个独立分组）

| 按钮文案 | 发送字符串 | 说明 |
|---|---|---|
| 站立 | `STAND` | **核心按钮**。服务端自动执行安全序列（位控站立→等待稳定→稳定站立），从按下到收到回复约 3~20 秒 |
| 吊起 | `吊起` | 切零力矩模式（悬挂/装箱用）。**需二次确认弹窗**：确认后机器关节失去力矩，无人扶会软倒 |
| 查询模式 | `MODE` | 回复格式 `OK:MODE:<模式名>:<状态>`，状态 0=空闲 100=运行中 200=切换中，建议解析后展示在界面上 |

可选追加：`位控站立`、`阻尼`、`走跑模式`（发送同名中文串）。

#### 二、挥手动作（在现有手势按钮区新增）

| 按钮文案 | 发送字符串 |
|---|---|
| 挥手 | `挥手` |
| 左手挥手 | `左手挥手`（若现有 UI 已有则跳过） |
| 右手挥手 | `右手挥手`（同上） |

### 回复协议（APP 侧展示逻辑）

- 成功：`OK:<指令>`；失败：`ERR:<指令>:<原因>`
- 例外：`JOY:<x>,<y>` 摇杆流式指令无回复，勿等 ack
- 建议在现有"服务端：…"日志区之外，把最近一条 ack 解析成 Toast/状态条提示

### UI/交互要求

1. **站立按钮防重复点击**：执行期间置灰或显示 loading，收到 `OK:STAND`/`ERR:STAND` 才恢复（安全序列耗时最长约 20 秒）
2. **吊起按钮二次确认**：弹窗警示"机器人将失去关节力矩，请确保已悬挂或平放"
3. **模式状态展示**（加分项）：顶部状态栏显示 `MODE` 查询结果，或在每次切换指令后自动发一次 `MODE` 刷新
4. 按钮文案用中文，发送的字符串必须与上表**逐字节一致**（勿加空格/前后缀；TCP 路径不加类型前缀）

### 标准操作顺序（用于 APP 内引导文案或说明书）

`吊起`（悬挂/装箱）→ 人工将机器人放到平地、双脚完全触地 → 按站立按钮 `STAND` → 稳定后再使用挥手/遥控等功能。预设动作（挥手等）要求机器人已处于稳定站立模式。

### 验收方式

1. 启动机器人侧：`source /home/agi/sztu/install/setup.bash && ros2 launch sztu_guide remote.launch.py`
2. APP 连接机器人 IP:8888，依次发送 `MODE`、`STAND`、`挥手`，确认各收到 `OK:...` 回复
3. 从开发机命令行手工发指令验证服务端行为：`tools/send_cmd.py`

   ```bash
   export SZTU_ROBOT_IP=<机器人上位机 IP>
   tools/send_cmd.py MODE STAND 挥手
   ```

   **不要用 `printf '挥手\r\n' | nc <机器人IP> 8888`** —— printf 一结束
   stdin 就 EOF，nc 立刻关连接，而手势/转手/模式切换都是慢路径、ack 要几秒
   后才回，那时 socket 已经没了。症状是"发出去了但什么都没看见"，很容易误判
   成服务端没响应。2026-10-01 在仿真上复现过：同一条 `引导右`，管道写法什么
   都收不到，把连接按住 18 秒才看到 `ERR:引导右`。
   非要用 nc 的话得按住连接：`{ printf '挥手\r\n'; sleep 10; } | nc <ip> 8888`。
