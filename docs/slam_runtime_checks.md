# SLAM 运行时修复与验证

自研链路仍是 FAST-LIO2 → lio_odom_bridge → /slam/lidar_odom。
本次修复不提供回环、地图匹配或重定位；从固定点启动和设置 sztu_up
不能证明跨趟地图对齐，也不能把闭合误差比例作为局部误差上界。

## SSH 真机启动前检查

在机器人 SSH 终端、启动 FAST-LIO 前执行：

```bash
cd ~/sztu
unset ROS_DOMAIN_ID
tools/run_lio_live.sh --check-only --bridge --map-frame maps/testroom.yaml
```

脚本自动加载厂商 ROS/DDS 环境，再设置本项目的 64 MB Fast DDS 配置。
话题检查使用 `--no-daemon --spin-time 5`，避免已有 daemon 的环境或发现缓存
造成误判。点云和 IMU 必须有发布者，已有 LIO 输出发布者仍会阻止重复启动；
检查通过只证明启动前条件满足，不证明消息持续更新。

2026-10-08 SSH 实测：点云 10.09 Hz、IMU 200.03 Hz；停止 ROS daemon 后，
上述只检查命令通过。此次验证未启动 FAST-LIO 或 bridge，也未执行实走。

随后 `20261008_162220_live` 短时测试录包约 21 秒：`/Odometry` 200 条、
10 Hz，无位姿跳变；bridge 输出 181 条，开始输出后与输入时间戳逐帧对应，
期间没有缺帧。日志报告的 6 条 TF 丢弃发生在输出开始之前。

实际参数复查，转角残差为 0.0000°。本趟腰关节未动，动态 TF 验证仍判不了
（退出码 2），不能据此认为实走或动态链路已经通过。

`20261008_170114_live` 动腰测试已通过 `check_lever.py`（退出码 0）：
腰偏航范围 89.21°、俯仰范围 19.10°，689 / 689 帧按时间戳配对，转角

准备测试时，先停止自启导航服务，再运行：

```bash
systemctl --user stop sztu-bridge
tools/run_lio_live.sh --bridge --map-frame maps/testroom.yaml
```

保持静止，等脚本提示初始化就绪后再按现场测试安排动作。结束按 Ctrl-C。

## 消息与定位状态

导航和 SlamManager 默认接收 odom → base_link 位姿。其他坐标约定需明确
设置 odom_frame / base_frame；不能仅改 frame_id 冒充坐标变换。
拒收过期、重复、倒序、明显未来时间戳，以及非有限位姿和零四元数。
数据寿命同时考虑 ROS 时钟的测量年龄和单调时钟的接收间隔，避免积压
数据或暂停的仿真时钟使旧数据持续有效。时钟倒退后需重新启动消费者。
回放须给消费者 use_sim_time:=true，并使用 ros2 bag play --clock。
真机须先保证传感器和消费者时钟一致。stamp_future_tolerance 默认 0.05 s，
用于容忍有限时钟误差，不应为接受旧数据而调大。

导航位姿寿命继续由到点容差 / 最大速度推导；SlamManager 的 odom_max_age
和 PoseMonitor 的 max_pose_age 默认 0.6 s。定位状态断流后失效。
PoseMonitor 保留输入坐标系和测量时间，过期后停止转发。

## 点云和 TF

避障接收当前 X2 的单行小端点云，要求 x/y/z 为 FLOAT32@0/4/8，
点数、数据长度和 row_step 一致。空帧、损坏帧、全非有限点按看不见停车；
有效点都落在检测走廊以外才可判前方畅通。
动态 TF 精确查询失败后，只接受与点云时间差不超过 obstacle_tf_max_age
的最新变换。默认 0.15 s 与桥接层现有退用阈值一致；这是时间预算，
并非障碍几何误差已经通过真机验证。

## 初始化和 FAST-LIO

bridge 自测重力要求连续两秒，默认不少于 200 帧、帧间隔不超过 0.05 s、
角速度不超过 0.05 rad/s、合成加速度标准差不超过 0.35 m/s²，平均模长
在 9.0–10.6 m/s²。这些是保守的初始门槛，仍需真实静止数据确认；
仅凭 IMU 无法排除恒定线加速度。运行脚本等待 bridge 重力就绪后才放行，
初始化超时会退出。给定 up_axis 时跳过自测，仍须人工保证静止初始化。

tools/setup_fastlio.sh 自动应用 tools/patches/fastlio_runtime.patch：
防止日志数组越界，先计算同帧协方差再发布，将局部姿态误差转成世界轴。
bridge 再传播重力旋转与杠杆臂。不包含关节 TF、外参不确定性；twist
仍未提供速度测量，不能据其零值判断机器人静止。

更新真机时需运行 tools/setup_fastlio.sh，重编 sztu_slam / sztu_navigation，
再重新启动节点。验证使用 ROS_DOMAIN_ID=42 tools/run_tests.sh；软件测试
与编译成功不代表实走停止距离、跨趟误差或硬件安全已验证。
