# 静止椅子对照的诊断范围

保持同一 LIO 会话及站位，`live=false`、三个感知覆盖标志均 false，不发送导航目标。
操作者已确认移动后 RViz 位置、朝向和扫描贴图基本正确。

先采集 `open_baseline`，再由操作者将椅子放到正前方距身体中心约 1.2 米处，
退到侧后方后采集 `chair_front`。最后移走椅子，在同一站位采集恢复背景作对照。
每阶段分别保存安全/定位扫描、速度指令、里程计，以及精确点云时刻 TF 转换的
三帧点云。当前适配器不改动；拟合地面后的投影仅作离线候选比较。

采集摆放阶段前确定诊断区域：身体中心正前方 ±20°、平面距离 0.7–1.7 米。
该范围包容操作者目测放置误差，不是机器人可行驶范围或避障放行阈值。
报告每帧此区域内的有效回波数、最近距离、存在回波的帧比例；启动前 5 秒
与之后的数据分别报告，保留全部年龄峰值。结合基线、摆放、移走三阶段变化
判断回波是否与椅子相关，不以孤立的一条回波判定检测成功。

原始点云中另报告拟合平面以上 0.05–0.60 米、且旧过滤排除的点数，检查
低于骨盆的椅子部分是否有回波。该高度来自点云拟合而非独立尺量，不能仅凭
点数确定每个点属于椅腿，也不能证明所有低矮障碍可检测。

保留各阶段位姿、数据缺失、拟合失败及地面拟合偏差。若机器人移动、椅子未
出现在指定区域或被遮挡，则记录实际情况，本次结果不按既定局部对照解释。
一次正前方椅子测试不验证左右视场边界、侧后方覆盖、动态避障或物理停止链路。

正前方三阶段完成后追加左右位置：同一把椅子分别位于左前方约 +30°、右前方
约 -30°，距离仍约 1.2 米。每次先等待操作者确认摆好并退开再采集。
对应诊断区域分别固定为 [+15°, +45°] 和 [-45°, -15°]、平面距离
0.7–1.7 米。背景使用同一站位的 `chair_removed`；左右摆放后再次移走并
复采。保留全部角度的分布，若放置角度偏出诊断区则报告偏差，不移动区域去
取得通过。该局部测试只检验所摆位置，不将角区有回波解释为区内连续覆盖。
