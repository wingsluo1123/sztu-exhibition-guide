# 小场地重新建图：先遥控采集，再离线建图

## 分工与数据位置

现场：学习者使用厂商遥控器操控机器人，保留遥控停止和接管能力。
机器人：沿用正在运行的传感器驱动，录制原始点云、雷达IMU、动态与静态TF。
电脑：助手通过SSH启动/停止录制，核对数据，复制到学习目录，再离线运行学习版FAST-LIO和栅格生成。
录制不等于建图，不发布运动指令，也不调用未购买的厂商SLAM。

现场信息由学习者提供：约7.2m×3m，三面墙，另一侧为桌椅；学习者已就位，遥控器可用。
建议保留桌椅位置，避免人员在扫描区域持续走动。标记起步位置和朝向，用于复现和对照。
实际距离与闭合程度没有独立测量，不将“回到附近”当作精确回环真值。

## 操作顺序

1. 机器人保持静止，助手检查连接、磁盘和实时传感器数据。
2. 停止旧项目sztu-bridge服务，确认navigation_manager退出，避免竞争控制。
3. 助手启动录制，确认四个话题实际写入后，才通知现场开始。
4. 起点静止约10秒；遥控器低速、平稳行走，有平移也有缓慢转弯。
5. 空间允许时走小环线，从不同位置观察三面墙和桌椅。没有余量就停稳，不强行凑环线。
6. 尽量回到起点附近及原朝向，静止约10秒；现场告知完成和异常。
7. 助手以SIGINT正常结束录制，检查metadata、话题消息数、传感器时间，再复制数据。
8. 电脑离线建图：本趟输入、本趟位姿、本趟地图一起保存；不沿用旧图变换、边界或点位。

建议采集2～3分钟，本次程序最多240秒后自动结束。录制自动停止不会代替现场遥控停车。
如果中途遇到人员、遮挡或转弯余量不足，先遥控停稳，再说明情况；不需要为了地图冒险完成路线。

## 需要明确的限制

同一次录包重跑FAST-LIO可能产生不同轨迹，正式选定图必须和对应位姿、点位一起保存。
本次重新采集改善观察覆盖，并不自动解决候选点时间解释、外参或累计漂移。
FAST-LIO不会因为走回起点就自动回环；墙面一致性由后续同高度、同墙段对照检查。
新场地不能复用lesson58冻结的旧地图变换与边界；需要从新数据建立自己的坐标和地板参考。
