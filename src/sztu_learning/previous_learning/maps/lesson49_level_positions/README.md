`transform.json` 为本次实际使用的变换配置副本。

R来自录包起始约2秒400条近似静止IMU的平均加速度方向；
结合FAST-LIO初始旋转为单位旋转，将该方向作为初始camera_init中的近似向上方向。
新Z沿该方向；新X由旧Y向候选水平面投影得到，新Y补成右手坐标系。
新X不代表已确认的机器人前方或指南针北方。
构造公式、初始假设和轴检查记录哈希见transform.json。
这是本学习目录新写的NumPy固定旋转工具，不调用旧项目的地图转换程序。
