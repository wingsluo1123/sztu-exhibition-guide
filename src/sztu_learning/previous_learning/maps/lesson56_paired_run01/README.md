## 文件怎么用

`frames.csv`是索引：秒、纳秒、NPZ相对路径、点数。`collection.json`是收集汇总。
`frames/`下每个NPZ包含四个命名数组：

| 名字 | 形状 | 含义 |
|---|---|---|
| xyz | N×3 | 本帧有效配准点，float32，米，camera_init坐标系 |
| position | 3 | 同时刻body原点在camera_init中的XYZ，米 |
| quaternion_xyzw | 4 | body相对camera_init的朝向，顺序x、y、z、w |
| stamp | 2 | 输出帧参考时间：整数秒、整数纳秒 |

这些点已在camera_init中，不能再误当雷达局部点重复施加body位姿。
