列1～6标0、列7标100；列8、9在命中后方，没有本次射线观测依据，所以仍未知。

此例直接指定水平路径格子，不是通用二维/三维射线跟踪算法。

核心make_example使用np.full初始化未知、np.arange给出水平路径列号，
ray_columns[:-1]取除最后一项外的路径格，ray_columns[-1]取命中格。
np.int8可保存-1/0/100；布尔数组只能表示两个值，不能表达本课三个状态。
没有重复观测更新、概率融合、先前障碍清除策略或导航加载功能。
