# 当前地图哪里不好，如何参考原项目改进

2026-11-20。诊断当前固定lesson57产物，不修改地图、参数、显示或原项目代码。
软件加载和逐格一致通过，不等于几何质量、物体识别和可导航性通过。

## 本次发现

1. **自由空间碎片化是当前观测规则的明确问题。** build_rviz_map.py的project_columns
   要求0.25～1.85m内16层全部至少2次穿过、并且每层累计命中为零才能判自由。
   一个弱命中会永久阻止该层自由，即使之后有很多穿过；“保守”不足以说明该规则适合实际数据。
   在明确选取的主体矩形X[-4.3,3.7]、Y[-1.8,8.8]内33920格，20889格未知（61.6%）。
   其中16368个未知格有至少一层弱/冲突命中，12389格有至少一层弱命中且不少于20帧穿过；
   10188格有完全未观测高度层。分类有重叠，弱命中不自动等于噪声，取样矩形也不是实测房间边界。
   这说明灰色既有真实观测不足，也有规则导致的长期不确定，不能全归因于“没有走到”。

2. **通道可用宽度不足。** 历史body中心到最近非自由格的格图距离中位约0.158m，
   5分位0.05m；中心不撞占据格仍不能证明整机可通过。该距离不是真实机体测量，
   body也不是已确定的地面碰撞中心，不能直接拿它决定实走安全或调小机器人尺寸。

3. **黑点、毛刺、墙边厚度需要分辨真伪。** 视觉上有零散占据和不整齐边界，
   部分可能是真实桌椅腿、家具、遮挡，部分可能来自人员、自体、姿态/点时间误差或点云噪声。
   仅凭最终二维图不能判定每个点属于哪一种。先看不同时间/视角是否重复支持，
   再做基于邻域与持续性的过滤；不按“小连通块”一刀切删除细障碍，不强行拉直实际墙面。

4. **地板/几何仍有不一致线索。** 当前拟合内点距离p95约6.24cm，是已选内点的统计，
   不是独立地板精度。对8m内近地回波按时间段比较，首末段共有336个20cm XY格，
   格内高度中位差的中位约4.7cm、95分位约10.1cm；该比较可能混有物体和采样差异，
   只能提示时间一致性待核对，不能直接宣称机器人漂移这些数值。
   应对重复静态墙面/地板作分段对应检查，必要时先修正时间单位/参考、外参和运动补偿。

5. **静态图覆盖与通行语义尚不完整。** 机器人主要沿中间往返，侧方家具后存在遮挡；
   确认是遮挡后需换视角补采。当前0.25m以下、1.85m以上及台阶落差未纳入完整碰撞判断，
   高度带需结合实际机体几何与可测地板误差制定；不能为了图白而抬高下界或忽略低矮障碍。

## 原项目怎么做

实际阅读tools/gridmap.py、src/sztu_slam/test/test_gridmap.py及maps/下说明。
这是仓库自研工具，与未采购的厂商SLAM/导航包无关，没有启动或研究厂商授权模块。

- fit_ground：高度直方图选低处候选、RANSAC/SVD拟合地板，以点到平面距离选障碍高度带。
  不把原FAST-LIO的Z直接认为竖直；默认离地0.25～1.80m。当前学习代码已拟合地板，
  这点不是缺失，区别主要是空闲模型。
- bearing_min_range + ray_samples：将高度带内点投影XY，按1800个方位桶取最近命中，
  在最近命中之前累积二维穿过证据。该方向没有命中就不生成该方向射线。
- classify：默认命中至少3次、占比至少0.20才为占据；穿过至少2次可为自由，
  足够多穿过时少数命中不永久阻止自由；没看过保持未知。占据条件成立时优先占据。
- 主循环默认使用所有帧；命中与穿过同为15m限距。点位/地图同源，轨迹只叠加到预览。
- **局限：** np.add.at计数是点/射线采样贡献数，不是独立观察帧数；
  相同一帧许多点可累计很多命中，阈值不能直接移植为“多帧支持”。
  高度折叠到二维后，二维穿过不等于整机高度范围均已可见；
  对低障碍、跨高度遮挡、稀疏/无回波和动态物体仍需单独验收。
  原项目sensor_origins直接取Odometry位置，其参考点假设也不能不核对就移植。
  原项目坐标系与本次地板对齐/180°坐标不同，地图接定位时必须使用本次完整变换。

## 建议的改进顺序

1. 先用现有冻结档案修正弱命中的融合规则：在同一高度层累计独立帧证据，
   允许反复清晰观测推翻孤立弱命中，稳定重复障碍优先；无观测层继续未知。
   将原项目二维核心方法作为基线，再比较保留高度信息的方案，不以自由面积最大为目标。
2. 对候选方案检查真实静态障碍是否保留、墙面厚度/断裂、未知与遮挡、
   通道连通和符合实际机体尺寸的路径。增加低障碍与高射线交错、细桌腿、人员穿过的控制例。
3. 对可疑毛刺按时间拆点云，核对地板/静态墙面一致性；确有姿态或时间问题时先处理上游。
   减少不必要的帧/射线丢弃，评估全帧与关键帧差别，按开销选取观测，不预先断言全帧一定更好。
4. 最后只针对确定的视角盲区安排补采：以多方向观察所需通道和点位为目的，
   不要求现在重走或连接机器人；明确移动条件后再执行。
5. 栅格与现场几何对得上、通道有实物依据后，再做定位/规划和实走验收。
   回环/重定位是整体项目后续能力，不能声称加回环即可消除当前规则造成的灰洞。

本轮仅诊断与参考对照，代码实现、地图、原项目及现场进程保持不变。
