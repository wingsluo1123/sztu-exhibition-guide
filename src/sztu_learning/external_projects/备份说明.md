# agibot-x2-navigation 本地备份

来源：https://github.com/Nova-Valley/agibot-x2-navigation

备份版本：`9ad1ad8af1b47b1d8fda42c3ca9c828bc5625629`。

- `agibot-x2-navigation/`：可直接查看的原始仓库，包含完整 Git 历史和已下载的 Git LFS 文件，未修改上游代码。
- `agibot-x2-navigation-full-9ad1ad8.tar.gz`：完整离线归档，包含源码、`.git` 和 LFS 对象；解压即可恢复，无需访问 GitHub。
- `agibot-x2-navigation-history.bundle`：独立 Git 历史备份。注意 bundle 本身不包含 LFS 实体，完整恢复请使用上面的 tar.gz。
- `agibot-x2-navigation-backup.json`：版本、数量、完整性检查与文件摘要。
- `SHA256SUMS`：归档校验值，在本目录执行 `sha256sum -c SHA256SUMS` 即可核验。

本目录设置了 `COLCON_IGNORE`，避免备份内同名 ROS 包影响现有工作空间编译。正式接入时另行安排构建。

此备份保存了当前 Git 仓库可获取的历史及 LFS 对象；作者未上传的录包、PCD 地图，以及系统依赖不包含在内。
