# 导航接入验证与成功程序

本目录用于先完成工程验证，再基于最终实现开展教学。学习笔记和逐步练习仍保留在../mapping_learning，不在教学目录堆积试验版本。

## 目标

复用已验证的固定地图和地图匹配定位，接入规划、实时障碍物与控制链路。实际验证终点和现场运动范围待用户明确。

## 用户已给出的条件

- 暂定外形宽0.60米、前后长0.40米；摆臂范围尚未计入确认。
- 人工测量以雷达外壳附近位置为参考，左右居中、距前缘约0.10米；不是已标定base_link原点。
- 旧地图、档案及真机部署保留，不覆盖。

## 协作方式

- 辅助诊断和验证由助手完成，暂停逐步提问式教学。
- 需要用户测量、选择或确认的环境参数，在使用之前说明含义、用途和建议，再由用户决定。
- 当前现场状态、目标点、最大速度、运动范围及停止条件需要本次现场确认；昨日状态不自动沿用。
- 默认先做离线及无执行器输出的检查；实际运动必须有现场操作人、独立停车手段和明确试验边界。
- 不启动厂商未授权SLAM/导航；实走前检查并停止sztu-bridge，确认唯一速度来源。
- 验证记录与成功入口分别保存，并区分软件通过、现场观测与尚未验证的条件。
