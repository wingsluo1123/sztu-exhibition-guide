## 可以使用的代码入口

本快照含定位适配、控制依赖和goal_navigation；不覆盖validated_straight_v2、validated_left_turn_v1。manifest.json记录文件哈希。本地教学仍使用mapping_learning目录。

机器人上运行goal_navigation/session.py，自动启动一套同源地图定位，再执行一个任务。接口说明见goal_navigation/README.md；run_navigate.bash用于已保持运行的定位旁接受一个新任务。默认只规划诊断，显式--execute-one-attempt才启用运动。每次新实走使用现场确认的目标/净空/边界，不直接反复重跑历史命令。

支持地图坐标--goal X Y、机器人朝向相对目标--relative-goal FORWARD LEFT、以及--rviz-goal接收/learning/nav/goal。三种入口进入同一规划与控制流程；这次实走使用相对目标。RViz配置含地图/路径/当前前向/目标；消息入口在隔离domain42验证过，**尚未完成“真人RViz点击后真机到点”验收**。

## 实际边界与未完成项

- “任意目标”表示程序支持地图内可达目标，墙内、未知区域、净空不足或超过本次距离预算的目标会拒绝。这次只独立实测一条短路线，绕障碍物的弯折路线、远距离目标和指定终点朝向仍只有软件验证。
- 无动态障碍物检测/避让；0.40m半径是用户同意的空场临时值，摆臂未标定，不能据此在有人展厅独立运行。
- 单目标完成后约75秒，保留运行的定位出现input_timeout_requires_reinitialization；无自动恢复。随后实时RViz目标诊断被预检挡住，没有注册运动源或发速度。**持续多目标运行稳定性尚未通过**，不能把本次单目标成功写成整套导览导航全部完成。
- 初始化仍可能因地板支持不足或地图歧义失败；不会自动忽略或带故障执行。初始位置确认仍依赖现场标记。未开展丢定位自动重定位、回环等长期运行验收。
- 此版运行于机器人开发计算单元。电脑负责测试、显示、证据保存。退出后试验/定位进程已结束，sztu-bridge保持inactive。

本版适合作为后续逐步教学的稳定代码参考；下一工程优先项为持续定位超时根因及RViz选点实走验收，之后再扩展连续点位和动态避障。
