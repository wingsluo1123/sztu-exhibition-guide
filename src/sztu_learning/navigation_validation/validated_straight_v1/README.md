## 依赖与运行位置

在机器人运行，使用既有~/sztu_learning/live_release01定位模块/地图和online_fastlio_ws编译产物；run_diagnostic.bash明确设置这些路径。电脑只保存源代码、测试与记录。原项目底层运动代码的快照在runtime_deps；没有修改原项目控制器。

入口run_once_session.py默认只做无速度诊断。实际运动需要显式--execute-one-attempt，以及本次现场目标、速度、时限、净空和遥控监督的决定，不能把本次许可当成以后一直有效。seed参数是IMU +Y投影在地图中的起始角，单位度，不能盲用旧值。

本次实测选项：--observe-deviation --speed 0.15 --duration 5。保留数据失效、MC状态、超时、总位移和不自动重试门禁。0.10米/秒的另一试验中用户观察未实际移动，因此没有把0.15认定为已标定的最低起步速度。
